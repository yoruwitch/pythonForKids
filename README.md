Este repositório foi criado como parte de um projeto muito especial realizado no meu último ano de graduação. A proposta da disciplina era solucionar um problema da minha comunidade ou introduzir a programação para um grupo de pessoas.

## 📚 Sobre o Projeto

Trabalho como professora de reforço escolar, atendendo alunos de 8 a 13 anos. Aproveitei essa oportunidade acadêmica para convidar os meus alunos alfabetizados e interessados a participarem de um "aulão de programação"!

Organizamos a aula em um sábado, fora do período de provas, e pedi que cada aluno trouxesse um notebook com acesso à internet. O objetivo era introduzir conceitos básicos de programação usando Python, além de familiarizá-los com o uso de computadores de forma mais ampla.

Foi um momento muito especial, onde trabalhamos:

- O que é programação.
- Introdução a linguagens de programação.
- Conceitos básicos de Python: variáveis, tipos de variáveis, entrada e saída de dados.
- Como usar um notebook: abrir pastas, acessar o navegador, etc.

Para facilitar a aprendizagem, utilizei o **Google Colab** como ferramenta principal, criando um notebook compartilhado com todos os alunos. A possibilidade de codificar diretamente no navegador, sem necessidade de instalar nada, foi fundamental para o sucesso da atividade!

No final, fizemos uma confraternização para celebrar a conquista — foram três horas intensas de estudo e diversão!

## 🚀 Como usar este repositório

1. Acesse o notebook através do Google Colab:  
   [![Open in Colab](https://colab.research.google.com/assets/colab-badge.svg)](https://github.com/yoruwitch/pythonForKids)

2. Ou clone o repositório para sua máquina:

```bash
git clone https://github.com/yoruwitch/pythonForKids.git
```

    Abra o arquivo .ipynb diretamente no Google Colab ou no Jupyter Notebook.
